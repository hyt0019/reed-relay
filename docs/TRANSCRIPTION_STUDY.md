# 《春日影》转谱对照与改进记录

## 资料与结论

本地音频 `春日影去除人声.wav` 为 44.1 kHz 双声道、256.673 秒。参考 `春日影（无杂音调音版）.mid` 有 593 个音符、约 97 BPM、251.907 秒。样例与派生谱不进入公开仓库。

旧转写有 2591 个完整候选，草稿 621 个音符。其中 E2 有 157 个、B2 有 93 个、F♯2 有 77 个、B1 有 52 个，明显倾向持续且激活值较高的低音。模型激活值不等于“这是主旋律”的概率。旧时间片算法没有休止选项，也没有足够的音区约束，低音会一直填满旋律空白。

旧草稿 616/621 个音带 +33.333 音分。来源是 Basic Pitch 的三分之一半音 contour 分箱，不能当作已校准的实际音准。新转写默认保留 MIDI 半音音高，把 contour 保存为分析数据；不会给所有音直接附加这一偏移。

## 参考 MIDI 与音频的差异

开头音频的稳态频率约为 625、557、496 Hz，对应 D♯5、C♯5、B4；参考 MIDI 则为 E5、D5、C5，高一个半音。参考 MIDI 的 DFHS1 嵌入数据记录 `transpose=0`，这只说明导出配置未再次移调，不能证明它与当前音源同调。

对照开头约 14 秒：把参考音高减一个半音、起点加 140 ms **仅用于评估**，在每个参考音的中点检查完整候选，32/36 个位置含有对应音。若按参考原音高检查，同一区间为 0/36。因此不可直接把参考音高套回音频并宣称保留原调。

同样的固定对齐应用于整曲，完整候选只有 95/593 个参考中点包含对应音。这个数字是特定对齐下的候选覆盖率，**不是整曲转写准确率**：参考谱可能有不同编排、节奏及声部；去人声文件也可能缺少参考中的演唱旋律。旋律选择只能改进已有候选的取舍，不能把这些缺失音符凭空恢复。

## 外部项目参考

[Delta-Force-Harmonica](https://github.com/Dr-hydra/Delta-Force-Harmonica) 同样使用 Basic Pitch 音频候选，同时支持 MIDI，区分原始音符、单声部筛选与口琴映射。其文档推荐 MIDI 或清晰的器乐音频，并提供针对短音、重复音、候选密度的筛选以及另一条符号旋律模型路线。它的自动移调属于明确的适配选项；本项目默认保留原调。

借鉴候选保留、声部连续性、音区与休止筛选的思路，独立实现并验证；没有复制该项目源码或引入其符号模型权重。

## 本轮验证目标

1. 强低音伴奏不能凭持续时间或音量接管清晰的上方旋律。
2. 短暂高音干扰不能切断长旋律音，快速的真实单声部与重复起音仍保留。
3. 音域筛选不移调；原始候选、人工微分音和撤销恢复不丢失。
4. 已知音频的模型识别仍维持原有起止时间误差范围，试听不再附加未经校准的 contour 偏移。
5. 真实样例的改进与剩余限制分别报告，并提供旧工程重新提取的操作。

## 旋律核心验证

`register-path-v2` 使用局部持续候选的加权音区、换音成本与休止状态；短高音的音区权重降低，偏离旋律音区的低音不再凭音量获胜。单声部直接保留，音域只筛选不改音高。新转写的所有候选默认 `cents=0`，原始 contour 仍单独保存。

使用同一份完整候选、同样的 −1 半音 / +140 ms 评估对齐、80 ms 碎音阈值：

| 检查 | 旧草稿 | 新草稿 | 完整候选覆盖 |
|---|---:|---:|---:|
| 去人声版，开头约 14 秒 | 8/36 | 25/36 | 32/36 |
| 去人声版，整曲 | 12/593 | 59/593 | 95/593 |
| 含人声原曲，整曲 | 81/593 | 292/593 | 396/593 |

旧用户工程的碎音设置为 140 ms；另用旧版算法和 80 ms / 50 ms 参数重新提取作对照，去人声版同样得到开头 8/36、整曲 12/593。表格含人声一行也使用相同的 80 ms / 50 ms 参数。匹配数统计参考音中点上是否存在同音，不代表完整音符时值和演奏已经准确。两版原曲长度差约 60 ms，固定对齐未进行节拍扭曲。

测试覆盖更强的低音叠加、三种速度、密集短高音装饰、旋律中的真正休止、限定音域后的快速重复音，以及真实 ONNX 模型的已知音高、晚段时序和混合声音。混合声音的 8 个旋律音至少 6 个被恢复，模型漏检仍存在；筛选不以低音填补漏音。
