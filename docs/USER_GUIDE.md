# 使用手册

## 听谱：从音频到可校对曲谱

1. 选择音频或拖入文件，可一次选择多首。主旋律优先生成单声部草稿；完整候选保留所有识别音符。
2. 点击开始转谱。后台依次处理每个文件，可以取消；某首解码失败不会使其余文件停止。完成的每首工程保存在数据目录的 `conversions` 中，主界面显示最近成功的结果。
3. 在钢琴卷帘或列表点击音符。橙色代表较低的模型分数，该分数不是经过校准的正确概率。时间轴可缩放为 12 / 24 / 48 秒视窗，并拖动下方滑块定位。
4. 试听原音可比较选中音符附近的片段；勾选循环可反复播放。取消选中后试听全曲。试听曲谱使用合成音，供比较音高与时值。
5. 修改起始毫秒、时长和 MIDI 音高；支持新增、删除、等分、合并下一同音高音符、撤销与重做。修改后自动保存，最多保留当前会话 50 步撤销。
6. 页面下方的当前场景检查可点击定位音域外、重叠和音分偏移等问题。是否可演奏取决于当前场景映射；它不是转写准确率评估。
7. 保存 JSON 工程可带走原始候选和修改结果；MIDI / 文本简谱导出当前编辑结果。若源音频搬家，点击关联原音重新选取，再保存工程。

原始候选始终单独保留；恢复原始候选会替换当前编辑列表，可撤销。主旋律提取只做单声部简化，不进行人声分离。声部筛选主要用于多通道 MIDI；音频转写不会自动识别每种乐器的身份。

文本简谱使用固定 `1=C4`、升降八度标记和绝对秒数，不改变原始音高。首版不估计 BPM、拍号或调式；工程 `bpm=120` 是参考占位，绝对事件时间不受它影响。微分音/滑音保存在 JSON 附加数据中，常规 MIDI 导出当前离散音符，不导出弯音曲线。

## 调音：建立自己的游戏场景

截图只确认了按键标签，没有确认真实音高。出厂模板为 C4–C5，三个修饰为 −12 / +1 / +12 半音；只有确认实际配置后才能启用真实输入。

1. 打开调音页，命名场景。A4 默认 440 Hz，可在 400–480 Hz 调整。
2. 测音来源默认「电脑声音」，选择游戏实际使用的耳机或扬声器，点击「开始测音」。回到游戏分别发出 8 个基础音；耳机模式也能直接采集，无需外放。也可切换为「麦克风」使用 Windows 默认录音设备，或点击「分析 WAV 单音」读取 16 位 PCM WAV（最多分析前 30 秒）。
3. 查看输入音量、音名、MIDI 数字与音分偏差，将检测到的 MIDI 数字手动填入音符键下方。C4=60、D4=62、E4=64、F4=65、G4=67、A4=69、B4=71、C5=72。每列可播放参考音比较；音区按钮统一增减八度。
4. 分别按住三个鼠标修饰键测音，填写相对基础音改变的半音数。再测量“降调+半音”和“升调+半音”，游戏支持时启用组合。
5. 改成自己的键位与全局热键。演奏键支持字母、数字、功能键、方向键以及 `MOUSE_LEFT / MOUSE_MIDDLE / MOUSE_RIGHT` 等；全局热键支持 Ctrl/Alt/Shift/Win 组合。
6. 勾选已核对音高和组合，保存并应用场景。导出场景只导出已保存值；下次启动自动载入。不同场景可分别导出，再导入切换。

测音仪按已保存的 A4 频率计算，修改参考值后先保存。软件改变的是识别参照和输入映射，无法直接改变游戏音源的调律；频率不同会给出提示。

### 电脑声音采集说明

- 使用 WASAPI 回环采集所选输出设备上的所有声音，当前没有按游戏进程隔离。测音时关闭游戏背景音乐，并暂停其他音乐/视频，每次弹奏一个稳定音。
- 设备列表优先选择系统默认输出；如果 Windows 音量混合器为游戏指定了其他耳机/扬声器，请选择游戏实际输出的那个设备。
- 点击「开始测音」才打开采集；「停止测音」、切换来源/设备、刷新设备或关闭程序会释放采集。电脑声音模式不启用麦克风，不保存或上传采集音频。
- 插拔耳机或改变 Windows 默认输出后，点击「刷新设备」重新选择，再开始测音。静音或没有收到声音时会清除旧音高并显示提示。
- 播放参考音会先停止测音，避免把程序自己的参考音当成游戏音高。比较完成后需再次点击开始测音。
- 声音较弱时检查所选设备、游戏音量与 Windows 音量；有音量但没有稳定音高时减少伴奏和同时发声的音符。
- 设备不支持回环、处于独占使用状态或受保护内容无法采集时，可切换麦克风或导入 WAV 单音录音。

## 风箱：预演与游戏演奏

1. 添加 JSON 或 MIDI 曲谱；也可直接载入原创练习曲。播放列表可用上下箭头排序。
2. 默认预演不发送系统输入。检查键位高亮、曲目进度与演奏检查列表。
3. 音域外音和重叠音默认阻止演奏。可手工校对，或显式选择提取主旋律、跳过音域外音。演奏移调默认为 0，所有演奏选项都不会修改原谱。
4. 刷新并选择游戏窗口，关闭预演。热键成功注册、场景确认校准、曲谱检查通过后可以开始。
5. 进入游戏演奏界面，按 F8。默认有 3 秒准备时间；F6/F7 切歌，F10 紧急停止。切歌默认停止，勾选“演奏中切歌后自动继续”才从新曲开头重新开始。

鼠标修饰先按下，音符随后按下；换音和停止会按顺序释放。游戏窗口失焦立即停止，需再次启动。实际输入使用 Windows SendInput；游戏可能受权限级别、输入处理方式或自身限制影响，不保证所有游戏都接受。

速度、准备时间、移调与简化选项会保存。每次启动仍默认预演，目标游戏窗口需重新选择，避免重启后把按键发送给错误窗口。

## 数据与排障

默认数据目录：`%APPDATA%\ReedRelay`。可通过环境变量 `REED_RELAY_DATA_DIR` 指定其他目录。

| 文件/目录 | 用途 |
|---|---|
| `profile.json` | 当前已保存场景 |
| `playlist.json` | 曲谱文件路径列表 |
| `preferences.json` | 演奏选项 |
| `conversions/` | 每首成功转换的完整工程 |
| `autosave.reedscore.json` | 最近编辑的恢复工程 |
| `audition_*.wav` | 临时曲谱试听音频 |
| `startup-player.log` / `startup-converter.log` | 便携程序启动失败时的诊断 |

- 热键注册失败：查看底栏信息，改用未被其他程序占用的组合。Windows 保留 F12，不能使用。真实演奏会等待热键就绪。
- 音高不对：先调音，再检查源音符；不要默认将 C4–C5 模板当作游戏实测值。
- 电脑声音没有设备或启动失败：连接耳机/扬声器后刷新；源码安装运行 `setup.ps1` 更新 PyAudioWPatch 依赖。电脑声音组件随两个独立包一同提供。
- 原音找不到：关联原音，再保存工程。曲谱文件不会嵌入原音频。
- 转谱依赖缺失：重新运行 `setup.ps1 -Module all`。ONNX 安装中缺少 TensorFlow/CoreML/TFLite 的提示不代表 ONNX 不可用。
- 找不到 Python：指定 `-PythonPath`；不要使用尚未在本项目支持范围内的 Python 3.14。
- 窗口内容未全部显示：界面可滚动，编辑/导出与保存场景按钮位于页面下方。
- EXE 无法启动：保留 EXE 旁完整 `_internal` 文件夹，检查启动日志。当前构建在本机 Windows / Python 3.12 环境验证，尚未完成所有 Windows 版本的兼容性矩阵测试。

## 命令行

```powershell
# 不启动 GUI 进行转谱（默认主旋律草稿）
.\.venv\Scripts\python.exe -m reed_relay.converter.transcribe 'input.mp3' 'output.reedscore.json'
# 保留全部候选
.\.venv\Scripts\python.exe -m reed_relay.converter.transcribe 'input.mp3' 'output.reedscore.json' --all-notes
# 便携听谱也可转换，出错时保存 output.reedscore.json.error.txt
.\dist\ReedRelay-Converter\ReedRelay-Converter.exe --transcribe 'input.mp3' --output 'output.reedscore.json'

# 可选硬件自检：播放 1.5 秒低音量 A4，采集默认输出并保存数值诊断（不保存录音）
.\dist\ReedRelay-Player\ReedRelay-Player.exe --check-loopback --output 'loopback-check.json'
```
