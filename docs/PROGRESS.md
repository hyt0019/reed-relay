## 2026-09-30 交付验证

- `python -m pytest -q`：31 项通过，包含真实 ONNX 模型的已知音高与 60 秒后事件对齐、混合成功/失败文件的批处理、编辑恢复、停止/失焦/异常释放、Windows 输入结构与亚毫秒 MIDI 导出。Resampy 的 `pkg_resources` 弃用提示通过固定 setuptools 兼容版本处理。
- `build.ps1 -Module all`：风箱与听谱各自打包成功。已修复构建环境 PATH 中不兼容 ICU DLL 被误收集，以及 Librosa/Resampy 的 Numba 源文件缓存路径问题。
- `packaging/smoke.ps1`：两个 EXE 均退出码 0；风箱主页、调音页和听谱主页成功渲染；打包听谱完整识别原创 6.6 秒测试音，得到 16 个音符。截图见 `docs/screenshots`。
- 打包听谱再次读取用户本地样例：全长 165.08 秒，1,708 个原始候选、912 个单声部草稿音符，保存完整候选与波形概览。原曲准确率仍需人工校对，不能将成功转换等同于逐音正确。
- 风箱包中未包含 Basic Pitch、ONNX Runtime、Librosa、SciPy 或 ImageIO-FFmpeg。便携包运行无需 Python 环境或另一个模块。
- 原生 F8/F6/F7/F10 热键已在 Windows 注册并释放；未向实际游戏发送测试按键，也未开启用户麦克风。
- 新增演奏选项持久化、列表排序与可选切歌继续、原音重关联、听谱问题定位。切换到失效曲谱文件时保持停止，不重新演奏旧曲。
