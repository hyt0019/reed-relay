# 实施与验证进度

方案依据：[产品与实施方案](../design/方案.md)。视觉依据：[A 谱台](../design/preview-paper.png)。

| 阶段 | 状态 | 验证与说明 |
|---|---|---|
| 1. 方案与仓库 | 已完成 | A 方案、自定义键位、调音、样例保留本地、阶段推送已写入方案。 |
| 2. 曲谱和调音核心 | 已完成 | 15 项测试通过：JSON/MIDI 音高时间往返、未知/非法值、键位冲突、鼠标释放顺序、重叠音及音域外提示、5 个已知音高与静音/泛音调音检测。 |
| 3. 风箱独立程序 | 待实现 | 预演、热键、按键释放、窗口守卫、调音与播放列表。 |
| 4. 听谱独立程序 | 待实现 | 解码、转写、校对、撤销、试听与导出。 |
| 5. 集成和交付 | 待实现 | 样例全曲、界面、安装和独立打包。 |

真实游戏内演奏须在用户的游戏会话中检查；本地演奏测试只使用预演或模拟输入接收器。
